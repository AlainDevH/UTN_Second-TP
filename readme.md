El proyecto desarrollado es un clon de Whatsapp con las siguientes características:
- Se puede ver la lista de contactos
- Se puede ver el chat con cada contacto
- Se puede enviar mensajes
- Se puede eliminar mensajes
- Cada chat tiene un header con el nombre del contacto, su avatar y su estado
- Cada contacto tiene su información, que se puede ver en el header
- Los mensajes se muestran con globos de diferente color según si son enviados por el usuario o por el contacto
- Se puede crear contactos nuevos
- Tiene una opción de modo claro y modo oscuro
- Los mensajes se muestran en orden cronológico
- Se puede buscar contactos en la barra de búsqueda del sidebar
- El sidebar se actualiza con los nuevos contactos
